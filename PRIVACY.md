# Privacy Policy

Lumio is a browser extension that runs locally in Chrome. It does not include analytics, telemetry, advertising scripts, or a bundled backend service.

## Data Stored Locally

Lumio stores the following data in `chrome.storage.local`:

- API URL
- API token
- Optional model name
- Preferred response language
- Auto-quote preference
- Recent conversation history

This data stays in the browser profile unless Chrome sync or another browser/profile-level backup feature copies it.

## Data Sent to Your AI Provider

Lumio only sends data when you use an AI action such as chat, translation, explanation, page summary, key point extraction, or glossary generation.

Depending on the action, Lumio may send:

- Selected text
- Extracted page text
- Page title and URL
- Conversation messages
- Your configured model name

Requests are sent directly from the extension to the API endpoint you configure. Review your provider's privacy and data retention policy before using Lumio with sensitive pages.

## Data Not Collected by This Project

Lumio does not collect or transmit:

- Browsing history outside the active page interaction
- Cookies
- Passwords
- Payment data
- Analytics events
- Crash reports

## Removing Data

You can remove Lumio's local data by uninstalling the extension, clearing extension site data from Chrome, or using Chrome's extension storage management tools.

## Contact

For privacy or security issues, open a GitHub issue or contact the project maintainer through the repository.
